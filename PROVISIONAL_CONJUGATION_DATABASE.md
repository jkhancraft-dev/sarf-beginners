# V10.7 provisional conjugation database

- `conjugation_database.json` is the shared directory for the 287 textbook inventory entries.
- Each verb record is keyed by `verbKey` and includes root, wazan, canonical lemma, meaning, finite conjugation tables and any nominal forms already present in the stored source facts.
- Finite tables use the standard 14-pronoun order for active/passive past and present; imperative is listed for the five addressee forms.
- The Conjugation of Verbs section loads this directory and displays it on each selected verb. The same finite forms are also added to `conjugation_data.json` facts so the existing question engine can quiz them.
- All generated entries are explicitly provisional. Existing source facts are retained; missing slots are generated by regular pattern/ending fallbacks. This is not a claim of lexical verification, and weak, hamzated, doubled, hollow, defective, quadriliteral, and unusual patterns require later review.
- `conjugation_database.json` is intentionally separate so other app modules can fetch and reuse one shared dataset rather than maintaining separate copies.
