# Verification sources

Primary source: Understand Al-Qur'an Academy, *All Verbs of the Qur'an*.

External lexical/Qur'anic checks used for the six former HOLD cells:
- Lane's Lexicon — صلّى / صَلَاة.
- Arabic terminology/dictionary sources — ضارّ, أبدى, أنار, تصدّى, تناجى.

Quranic Arabic Corpus is used as an external reference for Qur'anic morphology and verb-form conventions; it documents the corpus as a morphological/syntactic resource and provides a verb concordance grouped by root and form.
